# My Diary

A modern, simple, and user-friendly personal diary web application built with **HTML5, CSS3, and JavaScript**.

My Diary allows users to write, save, manage, and organize their personal thoughts, memories, notes, and daily experiences in a clean and responsive interface.

## Features

* Create new diary entries
* Edit existing diary entries
* Delete diary entries
* View diary entries
* Save entries using browser Local Storage
* Display entry date and time
* Responsive design for desktop, tablet, and mobile
* Clean and modern user interface
* Simple and easy-to-use navigation
* Data remains available after refreshing the browser
* Interactive JavaScript functionality

## Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and dynamic interaction
* **Local Storage API** — Saving diary entries in the browser
* **Git & GitHub** — Version control and project hosting

## How It Works

The application uses JavaScript to handle diary entries and browser **Local Storage** to preserve data.

When a user creates a diary entry:

```text
User writes entry
       ↓
JavaScript processes the data
       ↓
Entry is saved to Local Storage
       ↓
Diary entry appears in the interface
```

When the page is refreshed, the saved entries are loaded again from Local Storage.
